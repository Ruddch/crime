# Criminal Images Directory

This directory contains the criminal mugshot images for the PlasmaCrime website.

## Required Images

Place the following images in this directory:

1. **crypto-scammer.jpg** - Image for Crypto-Scammer (Pump & Dump)
2. **hacker-coder.jpg** - Image for Hacker-Coder (Rug Pull)  
3. **scheme-master.jpg** - Image for Scheme Master (Ponzi Scheme)
4. **meme-master.jpg** - Image for Meme Master (Over-memeing)
5. **space-con-artist.jpg** - Image for Space Con Artist (Moon Mission)
6. **token-terrorist.jpg** - Image for Token Terrorist (Token Terrorism)

## Image Specifications

- **Format:** JPG, PNG, or WebP
- **Size:** Minimum 200x200 pixels (will be resized to 120x120)
- **Aspect Ratio:** Square (1:1) recommended
- **Style:** Prison mugshot style, dark/ominous theme
- **Quality:** High resolution for crisp display

## Fallback

If images are not found, the system will automatically fall back to emoji characters:
- 👨‍💼 for Crypto-Scammer
- 👩‍💻 for Hacker-Coder
- 🤵 for Scheme Master
- 👨‍🎨 for Meme Master
- 👩‍🚀 for Space Con Artist
- 🧑‍💼 for Token Terrorist

## Usage

The images will be automatically loaded and displayed in the criminals carousel. They will be:
- Cropped to circular format
- Scaled to fit the 120x120 pixel container
- Enhanced with hover effects (zoom on hover)
- Styled with prison-themed borders and shadows
